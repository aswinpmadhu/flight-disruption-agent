# [agent] Approval-flow handlers, card and hooks (B-25)

**Phase: P1 · Wave 1 · Milestone cell: M2 · Priority P0 · Unassigned.**
**Blocked by:** B-12, B-14, B-17a, B-22, B-24. **Blocks:** B-32a, B-37, B-25-P2. **Effort:** 1.7 h (planning estimate; the claimant replaces it). **Class:** SC.
**Prep:** docs/03 §5.4 tools 6 to 8, §6.3a; the interface blocks of B-14, B-22, B-24.
**Scope:** handlers for `propose_rebooking_option`, `record_passenger_decision` and `execute_rebooking` (the `offer_alternative_search` handler is Phase 2, B-25-P2).
* `propose_rebooking_option` **creates** the pending `REBOOKING_OPTION` request from the app's own option map (with its `card_text`) and invalidates any earlier approval. `record_passenger_decision` is a **thin wrapper over `ConsentManager.decide`** and maps the result to the envelope. `execute_rebooking` reads PNR and `itinerary_key` from the pending REBOOKING request, calls `rebook`, and on success clears pending and records `outcome = REBOOKED`.
* **Hooks:** a `clean` hook appends the app-written card for each request in PROPOSED state and marks it PRESENTED with `presented_turn` (FR-22); the hook is **kind-agnostic**, and Phase 1 only ever creates `REBOOKING_OPTION`; an `always` hook calls `expire_turn_approvals`. The card text contains the app's instruction phrase so the echo rule can detect it.
**Interface (fixed here):** `build_handlers(*, consents, rebooking, settings) -> dict[str, Handler]`; `build_end_of_turn_hooks(*, consents) -> list[tuple[hook, when]]`, to be registered by the composition root.
**Files:** `flight_agent/agent/handlers_consent.py`, `tests/unit/test_handlers_consent.py`.
**Tests you own:** AT-01-R, AT-07-X, AT-19-P, FR25-H, SP-06-C (rebooking cards only), SP-07, SP-09-C (compromised model: forged decisions, forged rebooking, a forged `accept_search`, an unregistered `offer_alternative_search` call: all refused, booking unchanged, zero approvals). *Permitted tests: the forged-accept_search and unregistered-offer parts of SP-09-C are boundary or contract-shape tests under the dormant-contract exception defined in the Workflow block; they carry no Phase 2 test ID.* **Not yours:** AT-15, AT-17, AT-26 to AT-31 (B-22-P2, B-25-P2, B-23-P2).
