# [agent] get_booking and get_flight_status handlers (B-16a)

**Phase: P1 · Wave 2 · Milestone cell: M3 (P1) · Priority P0 · Unassigned.**
**Blocked by:** B-03, B-07, B-14, B-17a, B-23. **Blocks:** B-32a, B-37, B-03-P2. **Effort:** 0.75 h (planning estimate; the claimant replaces it). **Class:** -.
**Prep:** docs/03 §5.4 rows 1 and 2; the interface blocks of B-14 and B-23.
**Scope:** `get_booking` stores the **verified booking**, stores `reported_disruption` for S3 only (never authority), and on a not-found sets `AWAITING_PNR`; **a different verified PNR resets disruption, consent, pending request and options.** `get_flight_status` needs a verified booking; the flight must be a segment of it and the date must match the scheduled departure UTC date, else `FLIGHT_NOT_IN_BOOKING`; it records the status, lets the classifier update `session.disruption`, **returns `display` time strings**, and returns `search_plan` only when `SearchGuard` permits a search now. **For a status other than CANCELLED the result carries `workflow_note`: "this version handles cancellations only; no booking action is available".** `connection_impact` and the delay notes are not produced in Phase 1 (Phase 2, B-03-P2).
**Interface (fixed here):** `build_handlers(*, booking, flight_status, classifier, guard, settings) -> dict[str, Handler]`.
**Files:** `flight_agent/agent/handlers_read.py`, `tests/unit/test_handlers_read.py`.
**Tests you own:** AS-10, SP-02, SP-14, **SP-20** (a delayed or on-time status gives NONE, `search_alternatives` is refused `NO_DISRUPTION`, the note is present, nothing is booked; an **inline** test fixture, no delay data in `data/fixtures`), `test_handlers_read_*` (`NO_VERIFIED_BOOKING`, `FLIGHT_NOT_FOUND`, `AWAITING_PNR`). **Not yours:** `connection_impact` tests (B-03-P2).
**References:** FR-12, FR-13, FR-31; docs/03 §5.4.
