# [approval] Approval store and manager (B-22)

**Phase: P1 · Wave 1 · Milestone cell: M2 · Priority P0 · Unassigned.**
**Blocked by:** B-17a, B-21. **Blocks:** B-24, B-25, B-26, B-37, B-22-P2. **Effort:** 1.5 h (planning estimate; the claimant replaces it). **Class:** SC.
**Prep:** docs/03 §6; B-21's interface; B-17a's block. **The real PR is opened after B-21 merges; until then only a draft `[prep]` PR.**
**Scope (docs/03 §6.3, §6.3a, §6.4, §6.5, §8):** the **only** code that creates an `ApprovalRecord` (the search-consent record is Phase 2, B-22-P2). It implements the **approval path of the §6.3 decision table**:
* `approve_rebooking`: after L2 (a pending `REBOOKING_OPTION` exists, it was presented in an earlier turn, the message is the latest) and L3 (**`passenger_words` is an exact, case- and whitespace-sensitive substring of the latest message**; then the reply filter, passing `pending.card_text`), create the approval (ACTIVE; `session_id`, `pnr`, `itinerary_key`, `pending_version`, `granted_turn` copied from pending state). A refusal returns `REPLY_NOT_EXPLICIT` with `details.reason`, or `FLIGHT_MISMATCH`, or an L2 code, and changes nothing.
* **`accept_search` is refused and creates no record** (decision QD-12: dormant in Phase 1): `DECISION_KIND_MISMATCH` when a rebooking option is pending, `NO_PENDING_REQUEST` otherwise.
* `decline` clears the pending request and records `outcome = DECLINED` (FR-25). `unclear` changes nothing.
* `invalidate_approvals` (a new proposal or search), `expire_turn_approvals` (ACTIVE approvals from the turn become EXPIRED); the store is keyed by `session_id`; `consume` flips ACTIVE to CONSUMED under a lock.
* Trace events for grant, refusal (with reason), invalidation and expiry, with the payload fixed in B-18.
**Interface (fixed here):** `ApprovalRecord(session_id, pnr, itinerary_key, pending_version, granted_turn, status)`; `ApprovalStore.add`, `.active(session_id)`, `.consume(session_id)`, `.invalidate(session_id)`, `.expire_turn(session_id, turn)`; `ConsentManager(store, evaluate_reply, settings)` with **`decide(session, decision, passenger_words) -> DecisionResult(ok, effect, error_code, details)`** (`effect` one of `approval_granted`, `declined`, `no_change`; `search_consent_granted` is Phase 2), `invalidate_approvals(session)`, `expire_turn_approvals(session)`.
**Files:** `flight_agent/approval/store.py`, `flight_agent/approval/manager.py`, `tests/unit/test_consent_manager.py`.
**Acceptance criteria:** a forged `accept_search` is refused and creates no record; a same-turn approval is refused (`REQUEST_NOT_YET_PRESENTED`); the verbatim check is exact. *Permitted tests: AT-06 and SP-19 are boundary or contract-shape tests under the dormant-contract exception defined in the Workflow block; they carry no Phase 2 test ID.*
**Tests you own:** RF-07-S, RF-08-S, RF-11-S (approval subset), AT-01-A, AT-02 to AT-06, AT-07-D, AT-08, **SP-18** (same-turn approval of a rebooking option is refused, `REQUEST_NOT_YET_PRESENTED`; plan-level ID because the frozen AT-14 is the SEARCH_OFFER test), **SP-19** (a forged `accept_search` with nothing pending is `NO_PENDING_REQUEST` and creates no record), FR25-M, SP-05-M, S-1 (only the manager creates an `ApprovalRecord`). **Not yours:** AT-09 to AT-18, AT-26 to AT-31, F-BI, SP-03.
