# [session] TraceRecorder (B-18)

**Phase: P1 · Wave 1 · Milestone cell: M2 · Priority P0 · Unassigned.**
**Blocked by:** none. **Blocks:** B-17a, B-14, B-29a, B-19. **Effort:** 0.75 h (planning estimate; the claimant replaces it). **Class:** -.
**Prep:** none.
**Scope:** an immutable `TraceEvent`: `sequence`, `turn`, `kind` (`llm_call`, `tool_call`, `consent`, `approval`, `error`, `loop_limit`), `tool`, `arguments`, `result`, `source` (`llm` or `app`), **`allowed`**, `error_code`, `duration_ms`, `timestamp`, and `details` (a dict). **`allowed` is true exactly when the tool envelope has `ok: true`; a refused or invalid call is stored with `allowed = False` and its error code.** `TraceRecorder`: `record(...)`, `events` (a read-only ordered tuple), `calls(tool)`, `attempted(tool)` (any event for that tool name, allowed or not). Secret-looking values (`SecretStr`, keys named `api_key` or `authorization`) are redacted.
**Fixed here (payload of consent and approval events, read by B-29a and B-29b):** `details` carries `record` (`search_consent` or `approval`), `action` (`granted`, `refused`, `declined`, `invalidated`, `expired`, `consumed`), `reason` (filter reason or error code), `pnr`, `itinerary_key` (approvals only) and `pending_version`.
**Who writes events:** the **B-14 registry** records every tool call it receives; **B-22 and B-24** record consent and approval events; **B-19** records LLM calls and the loop limit.
**Files:** `flight_agent/session/trace.py`, `tests/unit/test_trace.py`.
**Tests you own:** `test_trace_*`: order preserved with no gaps; a denied call is distinguishable; a secret never appears in a stored event; the view cannot be mutated; `attempted` counts denied calls.
**References:** FR-10, NFR-09, D-08e; docs/03 §5.3, §8, §9.2.
